## 👨‍💻 About me

🎓 Computer Science undergraduate at **UEPB** (Campus I) — since 2022.
🔬 **Backend Developer** and undergraduate researcher (**PIBIC / FAPESQ-PB**) at **NUTES — Center for Strategic Health Technologies**, working across the **Usability & Human Factors Lab** and the **Biomedical Computing Lab**.

I build **cross-platform desktop applications** (C# / .NET / Avalonia), **high-performance REST APIs** (ASP.NET Core and FastAPI), and **Virtual Reality experiences** for healthcare. I focus on clean code, well-separated architecture (**MVVM**, **Clean Architecture**), agile delivery (**Scrum**), and disciplined review before every delivery.

### ⭐ Featured project — Fatia de Ouro *(freelance)*

**A complete ERP + POS system for a bakery**, from design to delivery, built as a freelance project and **currently in production** running the client's checkout. Shipped as a **self-contained single Windows executable** (Inno Setup installer): the owner installs and runs it with no extra runtime.

- 🛒 **Full POS** with keyboard shortcuts and barcode scanner, designed for a non-technical operator.
- 📦 **Products, Inventory, Expenses and Reports** modules.
- ⚡ **Optimized for low-end hardware** (4 GB RAM, 1024×768 display) — list virtualization, DB-side paging, short-lived `DbContext`.
- 🔐 **BCrypt authentication** and owner approval of sensitive actions via **email token** (MailKit).
- ☁️ **Cloud licensing** (Supabase + Cloudflare Worker) with **automated recurring billing** and **resilient offline-first sync** (local SQLite + remote backup, last-write-wins reconciliation).
- 🧱 **MVVM** architecture with dependency injection; persistence on **SQLite + EF Core 9** (WAL mode).

`C#` · `.NET` · `Avalonia UI` · `MVVM` · `EF Core 9` · `SQLite` · `Supabase` · `Cloudflare Workers` · `MailKit` · `BCrypt`
